    FAQ

    Questions, answered.

    Still unsure about a result? Open the reference to see exactly which fields differ, or mark it as verified if you’ve checked it yourself.

    Is my paper uploaded anywhere?

    No. PDFs and reference lists are read inside your browser. Only individual titles, DOIs and arXiv IDs are sent to the public databases to look them up, and nothing is stored.

    Does “Not found” mean a reference is fake?

    Not necessarily. Books, theses, reports and very new work are sometimes missing from all five databases. Check those by hand, then use “Mark as verified” so they count as confirmed.

    Which databases are checked?

    CrossRef, DBLP, Semantic Scholar, DataCite for arXiv, and OpenAlex when you add a free key. Retraction data comes from CrossRef, which includes the Retraction Watch database.

    Will the corrected .bib break my citation keys?

    No. Your original keys are kept, so every \cite{} in your paper still works. Each change is noted in a comment above the entry, and you can switch any correction off.

    Do I need an account or an API key?

    No account is needed. An OpenAlex key is optional and free. It adds one more database for the widest coverage.
