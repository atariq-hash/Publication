Check your reference list

Paste a bibliography and each entry is looked up in CrossRef, DBLP, Semantic Scholar, arXiv and OpenAlex. You’ll see which citations match a real publication, which have mismatched details, and which can’t be found at all.

Options

Adding your email puts requests in CrossRef’s faster “polite” pool. It’s only sent to CrossRef and OpenAlex.

OpenAlex needs a free API key for more than a few lookups a day. Get one at openalex.org/settings/api and paste it here. Without it, only CrossRef is used once the free quota runs out.

Results

OpenAlex refused some lookups because there’s no API key or the daily quota ran out. Those references were checked against CrossRef only, so some “Not found” results may be real papers. Add a free OpenAlex key under Options and check again.

Entries marked “Check details” are replaced with the corrected version unless you untick them. Verified entries are kept as they are, and entries that weren’t found are kept with a note so you can check them by hand.

    A “not found” result means no close match turned up in any of the databases. Books, reports, theses and very new papers are sometimes missing from both, so check those by hand before treating them as fabricated.
